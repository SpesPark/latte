중요한 순간에 Mac이 잠들지 않게.

Latte는 회의·발표·다운로드·당신의 하루 어디서든 알아서 깨어있는 메뉴바 유틸리티입니다. 다른 "잠금 방지" 앱들과 달리 직접 켜고 끌 필요가 없습니다 — Latte가 상황을 보고 알아서 결정합니다.

왜 Latte인가

화상 회의 한가운데. 화면이 꺼지고 Mac이 잠듭니다. 화면 공유가 끊깁니다. 매번. 겨우 발표 전에 카페인을 켰는데, 끝나고 끄는 걸 잊어 Mac이 주말 내내 깨어있고 월요일 아침엔 배터리가 0%. Latte는 두 문제를 자동화로 해결합니다. 한 번만 설정하면 그 다음부터 잊고 살아도 됩니다.

6가지 스마트 트리거

캘린더 — 일정이 잡힌 시간 동안 깨어있게 합니다. 어떤 캘린더가 Latte를 작동시킬지 골라보세요 (업무 캘린더만, 개인 생일 일정은 제외). 회의 시작 몇 분 전부터, 끝난 후 몇 분까지 — 사전/사후 시간을 직접 조정할 수 있습니다. "하루 종일 일정은 제외" 옵션으로 생일 알림에 Mac이 종일 깨어있는 일도 막습니다.

앱 — Zoom, Microsoft Teams, Webex, Discord, Slack, Google Meet, 또는 직접 고른 앱이 실행 중일 때 활성화됩니다. 앱 선택기는 실제 앱 아이콘과 친숙한 이름으로 표시됩니다. Bundle ID 같은 거 찾을 필요 없이, 실행 중인 앱을 한 번 클릭으로 추가할 수 있습니다.

Wi-Fi — 회사 네트워크에서는 깨어있고, 집 Wi-Fi에서는 잠들게. 반대로도 설정할 수 있습니다. SSID는 여러 개 등록 가능합니다.

포커스 — macOS 집중 모드가 켜져 있는 동안 깨어있습니다. 방해 금지로 집중하는 중인가요? 손 하나 까딱하지 않아도 화면이 살아있습니다.

일정 — 당신의 시간표대로 깨어있게. 요일과 시간대를 고르면 — 월~금 9시~6시든, 당신의 하루가 어떻든 — Latte가 알아서 챙깁니다. 자주 쓰는 패턴은 저장해 두세요.

외부 디스플레이 — 모니터가 연결돼 있는 동안 깨어있습니다. 책상에 도킹해 두셨나요? Mac은 깨어있고, 뽑으면 다시 잠들 수 있습니다. 내장 화면은 포함되지 않습니다.

트리거는 함께 투표합니다. 한 트리거라도 "깨어있어"라고 말하면 Latte는 깨어있습니다. 마지막 트리거가 "잠들어"라고 말하면 즉시 해제합니다 — 숨겨진 대기 시간도, 의외의 배터리 소모도 없습니다.

수동으로도 메뉴바에서 켤 수 있습니다 — 15분, 30분, 1시간, 2시간, 커스텀 (1~1440분), 또는 "끌 때까지". 수동·자동 모드가 함께 동작합니다.

Latte의 차별점

대부분의 "잠금 방지" 앱은 켰다 껐다 직접 해야 합니다. Latte는 다릅니다 — 상황을 보고 알아서 결정합니다.

• 캘린더 인식: 캘린더 이벤트를 보고 자동 활성화하는 메뉴바 유틸리티는 거의 없습니다.
• 메뉴바 상태 표시: 활성화 시 컵이 가득 차고, 비활성 시 비어 있습니다. 한 번 보면 바로 알 수 있습니다.
• 설정하고 잊기: 첫 실행 위저드에서 자동 시작과 트리거를 한 번에 설정하면 다시 손댈 필요 없습니다.
• 활동 기록: Latte가 언제 — 그리고 왜 — Mac을 깨워뒀는지 24시간·14일 차트로 확인하고, CSV나 JSON으로 내보낼 수 있습니다.
• 단축키 한 번: 전역 키보드 단축키(기본 ⌘⇧L, 자유롭게 변경 가능)로 어디서든 카페인을 켜고 끕니다.
• 구독 절대 없음. $2.99 한 번 결제하면 평생 — "Plus" 등급도, 업그레이드 구독도 없습니다.

macOS를 위해 만들어진 디자인

네이티브 SwiftUI 메뉴바 앱. 카페인이 켜져 있을 때 김이 모락모락 피어오르는 커피컵 뷰가 함께합니다. 메뉴바 아이콘도 활성 상태일 때 가득 찬 컵으로 변해, popover를 열지 않아도 한눈에 확인할 수 있습니다. 6가지 톤 중에서 골라 메뉴바 분위기에 맞춰보세요 — 에스프레소, 캐러멜, 모카, 라떼, 말차, 누아르. macOS 26 Tahoe에서는 컵에 Liquid Glass 효과가 자동으로 적용됩니다.

진짜 사적인 프라이버시

Latte는 어떤 데이터도 수집하지 않습니다. 분석 SDK 없음, 텔레메트리 없음, 어디로도 네트워크 호출 없음 — 애초에 서버가 없습니다. 캘린더는 읽기 전용, Wi-Fi 네트워크 이름과 앱 목록은 Mac을 떠나지 않으며, 모든 설정은 로컬 UserDefaults에만 저장됩니다. 전체 개인정보처리방침은 사이트(아래 링크)에서 확인할 수 있습니다. 평이한 한국어, 함정 없음.

시스템 요구사항

macOS 13 Ventura 이상, Apple Silicon 권장. 캘린더·Wi-Fi·포커스 트리거는 각각 켤 때만 해당 권한을 요청하며, 앱 실행 시점에는 요청하지 않습니다 (Wi-Fi는 SSID를 읽기 위해서만 위치 서비스를 쓰고, 위치 정보는 읽지 않습니다). 일정·외부 디스플레이 트리거는 아무 권한도 필요하지 않습니다.
