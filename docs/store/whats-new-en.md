Initial release.

Latte keeps your Mac awake automatically, based on context — calendar events, running apps, Wi-Fi network, a time-of-day schedule, or a connected external display. Configure once, then forget about it.

This first version includes:
- Five smart triggers (Calendar, Apps, Wi-Fi, Schedule, External Display)
- Manual menu bar toggle (15 min / 30 min / 1 h / 2 h / custom 1–1440 min / until off)
- Activity history with 24-hour and 14-day charts and a filterable event list
- A global keyboard shortcut to toggle caffeine (⌘⇧L by default, fully rebindable)
- Six coffee accent tones for the cup view
- Three menu bar icon styles (filled, outlined, clock)
- 11 languages — English, Korean, Japanese, Simplified & Traditional Chinese, Spanish, German, French, Brazilian Portuguese, Italian, and Russian
- Zero data collection, zero network calls

macOS 13 Ventura or later. Apple Silicon recommended.
