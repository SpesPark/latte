Initial release.

Latte keeps your Mac awake automatically, based on context — calendar events, running apps, Wi-Fi network, Focus mode, a time-of-day schedule, or a connected external display. Configure once, then forget about it.

This first version includes:
- Six smart triggers (Calendar, Apps, Wi-Fi, Focus, Schedule, External Display)
- Manual menu bar toggle (15 min / 30 min / 1 h / 2 h / custom 1–1440 min / until off)
- Activity history with 24-hour and 14-day charts, exportable as CSV or JSON
- A global keyboard shortcut to toggle caffeine (⌘⇧L by default, fully rebindable)
- Six coffee accent tones for the cup view
- Three menu bar icon styles (filled, outlined, clock)
- Korean and English localization
- Zero data collection, zero network calls

macOS 13 Ventura or later. Apple Silicon recommended.
