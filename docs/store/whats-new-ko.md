Latte는 캘린더 일정, 실행 중인 앱, Wi-Fi 네트워크, 집중 모드 — 상황에 따라 자동으로 Mac을 깨어있게 합니다. 한 번 설정하고 그 다음부터는 잊고 살아도 됩니다.

이번 버전에 포함된 기능:
- 4가지 스마트 트리거 (캘린더 / 앱 / Wi-Fi / 집중 모드)
- 메뉴바 수동 토글 (15분 / 30분 / 1시간 / 2시간 / 커스텀 1–1440분 / 끌 때까지)
- 5가지 커피 톤 테마
- 3가지 메뉴바 아이콘 스타일 (채움 / 윤곽선 / 시계)
- 한국어 + 영어 지원
- 데이터 수집 0, 네트워크 호출 0

macOS 13 Ventura 이상. Apple Silicon 권장.
